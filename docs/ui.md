旧博客路由功能拆解

1. 主页
   https://blog.384385.xyz/my-blog/
2. header 交互
   点击 隧道 跳转到 https://blog.384385.xyz/my-blog/archives/
   点击 分类 跳转到 https://blog.384385.xyz/my-blog/categories/
   点击 标签 跳转到 https://blog.384385.xyz/my-blog/tags/
3. 文章详情页
   点击文章卡片 跳转到 类似 https://blog.384385.xyz/my-blog/2025/02/18/%E6%A1%8C%E9%9D%A2%E5%BA%94%E7%94%A8%E5%BC%80%E5%8F%91%E6%A1%86%E6%9E%B6%E9%80%89%E6%8B%A9/ 这个页面
4. 分类页
   点击分类tab或链接 跳转到 类似 https://blog.384385.xyz/categories/%E5%89%8D%E7%AB%AF%E5%BC%80%E5%8F%91/
5. 点击标签 tab 或链接 跳转到 类似 https://blog.384385.xyz/tags/AI/
