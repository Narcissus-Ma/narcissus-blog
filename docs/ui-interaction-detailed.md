# 旧博客路由 UI 交互细化（基于页面实测）

> 采集时间：2026-03-09  
> 采集方式：逐个打开 `docs/ui.md` 中链接并读取页面可交互元素（导航、按钮、链接、筛选、列表、弹层等）

## 1. 路由与页面总览

| 路由                                                                       | 页面定位 | 交互定位                               |
| -------------------------------------------------------------------------- | -------- | -------------------------------------- |
| `https://blog.384385.xyz/my-blog/`                                         | 首页     | 导航入口 + 分类快捷入口 + 文章流主入口 |
| `https://blog.384385.xyz/my-blog/archives/`                                | 归档页   | 年月聚合时间线浏览                     |
| `https://blog.384385.xyz/my-blog/categories/`                              | 分类总览 | 分类入口页（按分类数展示）             |
| `https://blog.384385.xyz/my-blog/tags/`                                    | 标签总览 | 标签云入口页（按标签数展示）           |
| `https://blog.384385.xyz/my-blog/2025/02/18/.../`                          | 文章详情 | 阅读、分享、上一篇/下一篇、目录定位    |
| `https://blog.384385.xyz/categories/%E5%89%8D%E7%AB%AF%E5%BC%80%E5%8F%91/` | 分类详情 | 某分类下文章列表                       |
| `https://blog.384385.xyz/tags/AI/`                                         | 标签详情 | 某标签下文章列表 + 标签切换            |

## 2. 全局 UI 交互（多页面共通）

1. 顶部导航

- Logo 点击回首页。
- 主导航：`隧道`、`分类`、`标签` 直达对应列表页。
- 快捷图标：
  - 随机文章（`toRandomPost()`）
  - 搜索
  - 显示模式切换
  - 回到顶部

2. 搜索交互

- 点击搜索图标可打开搜索弹层。
- 弹层包含输入框（占位：`搜索文章`）和关闭按钮。
- 支持快捷键提示（页面上显示 `Ctrl+Alt+s`）。

3. 侧栏与底部统计

- 侧栏有作者卡片、标签统计、归档统计。
- 底部固定统计入口：`文章`、`标签`、`分类`，均可点击跳转。

4. 悬浮工具/增强交互

- 简繁切换按钮。
- 深浅色切换按钮。
- 单栏/双栏切换按钮（首页可见）。
- 设置按钮、回到顶部按钮。
- 音乐播放器入口（含歌词面板）。
- 右键菜单（DOM 中可见入口项）：引用评论、随机逛逛、分类/标签入口、复制地址、模式切换等。

## 3. 各路由细化交互

### 3.1 首页 `/my-blog/`

1. 首屏快捷区

- `随便逛逛`：触发随机文章跳转。
- 分类快捷按钮：`前端开发`、`服务端开发`、`人工智能`、`生活日常`。

2. 内容流

- 文章卡片支持多入口点击：封面、标题、`未读`标记。
- 卡片元信息可继续跳转：分类、标签、发布日期。
- 列表底部有分页区，包含页码与跳页输入框（`toPage`）。

3. 侧栏辅助入口

- 标签统计可点击跳转标签页。
- 归档月份卡片可点击跳转指定年月归档。

### 3.2 归档页 `/my-blog/archives/`

1. 时间线交互

- 按年份/月份组织文章。
- 每条归档项支持封面、标题、标签点击。
- 点击标题或封面进入详情页。

2. 聚合入口

- 月份统计入口（示例：`二月 2025 8篇`）可点击。

### 3.3 分类总览 `/my-blog/categories/`

1. 分类清单

- 以 `#分类名 + 文章数` 展示（示例：`#前端开发 5`、`#人工智能 3`）。
- 点击后跳转到分类详情页（路径为 `/categories/:slug/`）。

### 3.4 标签总览 `/my-blog/tags/`

1. 标签云

- 以 `#标签 + 数量` 展示（示例：`#AI 3`）。
- 点击后跳转到标签详情页（路径为 `/tags/:slug/`）。

### 3.5 文章详情页（示例链接）

1. 阅读区

- 顶部展示：标题、分类、标签、原创标识。
- 正文内标题带锚点链接。
- 目录（TOC）可点击定位正文章节。

2. 内容传播

- 分享区：微信、微博、QQ、Twitter、Facebook 等入口。
- 版权区：作者、原文链接、版权协议信息。
- 赞赏入口按钮。

3. 阅读流转

- 上一篇/下一篇跳转。
- 侧栏“最近文章/推荐”继续阅读入口。

### 3.6 分类详情 `/categories/:slug/`

1. 分类上下文

- 页面标题为 `分类: xxx`。
- 顶部有分类导航条（如首页/人工智能/前端开发/更多）。

2. 筛选结果

- 页面主体展示该分类下文章列表（封面、标题、标签、日期）。
- 点击文章项进入详情页。

### 3.7 标签详情 `/tags/:slug/`

1. 标签上下文

- 页面标题为 `标签: xxx`。
- 顶部标签条支持切换不同标签，当前标签有选中态（`selected`）。

2. 筛选结果

- 展示当前标签关联的文章列表。
- 列表项支持封面、标题、标签点击。

## 4. 实测发现的交互问题（可作为迁移时的规避清单）

1. 分类快捷按钮链接异常

- 首页 `服务端开发` 按钮实际跳转到“前端开发”分类链接，疑似配置错误。

2. 路径前缀不一致

- 页面主入口大量使用 `/my-blog/...`。
- 分类/标签详情实际落到 `/categories/...`、`/tags/...`（无 `/my-blog` 前缀），存在命名空间不一致。

3. 随机跳转稳定性风险

- 随机入口实际触发时出现过跨路径跳转（从 `/my-blog/` 跳到根路径文章地址），需要在新项目里统一随机跳转规则。

4. 回到顶部数值异常

- 在分类总览页观察到回顶计数显示 `NaN`，属于可见 UI 异常。

## 5. 可直接映射到新项目的交互需求

1. 必做交互

- 顶部三主导航（隧道/分类/标签）。
- 首页文章卡片多点击入口（封面/标题/标签/分类）。
- 分类总览 -> 分类详情、标签总览 -> 标签详情完整闭环。
- 详情页 TOC、上一篇/下一篇、分享区。

2. 建议增强交互

- 搜索弹层（而不是仅输入框跳转）。
- 浮动工具组（主题、回顶、布局切换）。
- 标签详情页选中态与切换体验。
